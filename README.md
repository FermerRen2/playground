# RoofMap — стартовый прототип

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html` и `roofmap-data.json` в корень репозитория.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. GitHub покажет адрес сайта после публикации.

## Как пользоваться
- `Рисовать`: нажимайте по схеме, чтобы поставить вершины контура. Нажмите «Готово» или дважды кликните, чтобы завершить.
- `Метка`: нажмите на нужное место и заполните карточку.
- `Просмотр`: открывайте существующие метки.
- `Экспорт`: скачивает `roofmap-data.json` со всеми схемами и метками.
- `Импорт`: загружает ранее экспортированный JSON.

## Как публиковать свои изменения для всех
1. Редактируйте сайт в своём браузере. Черновик автоматически сохраняется локально.
2. Нажмите «Экспорт».
3. Замените файл `roofmap-data.json` в GitHub-репозитории на скачанный файл (можно прямо через сайт GitHub: Add file → Upload files).
4. После обновления GitHub Pages новые посетители увидят обновлённую схему.
5. На своём устройстве локальная копия имеет приоритет. Чтобы загрузить опубликованную версию заново, очистите данные сайта для этого домена в браузере или используйте окно инкогнито.

## Важно
- Без сервера браузер не может сам записывать изменения в GitHub. Поэтому публикация обновлений — через экспорт и замену JSON-файла.
- Админ-переключатель — только интерфейсный режим, НЕ защита. Любой посетитель может включить его. Не размещайте секреты или приватные данные.
- GitHub Pages публичен: опубликованные схемы и ссылки доступны посетителям сайта.
- Google Drive: для встроенного просмотра файлов нужен доступ «Все, у кого есть ссылка». Для Google Drive используется preview-встраивание; Google может ограничивать предпросмотр некоторых файлов.
- Для прямых ссылок на изображения и видео используются обычные HTML-плееры.
