# PLAYGROUND

Творческая площадка: мелкие эксперименты, мини-игры и генеративная графика.
Всё на чистом HTML, CSS и JavaScript — без сборщика, без зависимостей, без `npm install`.
Открывается двойным кликом по `index.html` или живёт на GitHub Pages.

## Что внутри

| Эксперимент | Что делает | Файлы |
|---|---|---|
| **Shared Field** | Мультиплеер: все, кто зашёл в комнату, видят друг друга вживую и толкаются. Соединение напрямую между браузерами | `games/shared-field/` |
| **Case Battle** | Кейс-баттл на живых игроков: каждый вскрывает кейсы за игровые монеты, побеждает самый дорогой дроп и забирает весь банк | `games/case-battle/` |
| **Neon Snake** | Классическая змейка со светящимся следом, ускорением и рекордом в браузере | `games/neon-snake/` |
| **Flow Field** | Тысячи частиц, ведомые невидимым векторным полем; мышь их притягивает | `games/flow-field/` |

## Структура

```
index.html            витрина: сетка карточек
style.css             общие стили (тёмный неон)
main.js               фоновое поле частиц на витрине
lib/
  trystero.bundle.js  WebRTC-соединение между браузерами (собран из npm, 73 КБ)
games/
  shared-field/
    index.html
    field.js
  case-battle/
    index.html
    battle.js
    items.js
  neon-snake/
    index.html
    game.js
  flow-field/
    index.html
    flow.js
```

Каждый эксперимент самодостаточен: своя папка, свои скрипты, общими остаются только
`style.css` (подключается через `../../style.css`) и приёмы оформления. Сломать один,
не задев другие, — нормально и ожидаемо.

## Как добавить новый

1. Создать папку `games/<имя>/` с `index.html` и скриптом.
2. В `index.html` внутри папки подключить `../../style.css`, добавить ссылку «← назад» на `../../`.
3. В корневом `index.html` добавить карточку в `<main class="grid">`.

## Локальный запуск

Двойной клик по `index.html`. Если браузер капризничает с локальными файлами:

```powershell
npx serve .
# или
python -m http.server 8000
```

`shared-field` и `case-battle` требуют http, а не `file://`: страницы используют ES-модули.

## Мультиплеер: как это устроено и почему так

На GitHub Pages нет сервера — только файлы. Значит, передавать данные между игроками
приходится либо через чужой сервер, либо напрямую между браузерами.

**Выбрано: напрямую (WebRTC).** Браузеры находят друг друга через публичные
Nostr-релеи, дальше данные идут минуя серверы, между самими игроками. Ни аккаунтов,
ни ключей, ни развёртывания.

**Что было проверено и забраковано (замеры на этой машине):**

| Транспорт | Результат |
|---|---|
| PeerJS (публичное облако) | не работает: брокер отвечает `network`, id не выдаётся |
| Публичные MQTT-брокеры (EMQX, HiveMQ) | доставка 0–11%, паузы до 30 секунд — для реального времени непригодно |
| WebRTC через Nostr-релеи (Trystero) | 144 из 151 сообщения за 30 секунд, поток без провалов |

Список релеев прописан вручную (`RELAYS` в коде игр): из 33 проверенных живыми оказались
30, мёртвые исключены, чтобы не тормозить поиск друг друга.

**Честное ограничение:** WebRTC не всегда пробивает симметричные NAT и строгие
корпоративные сети — тогда два игрока не соединятся. Свой TURN-сервер это лечит,
но он снова требует хостинга, поэтому пока не делаем.

**Комната** задаётся в адресе: `games/shared-field/#имя-комнаты`. Кнопка «ссылку другу»
копирует адрес с текущей комнатой.

## Case Battle: правила и честность

1. У каждого 1000 игровых монет. Кейсы стоят 50, 150 и 500.
2. Вскрыл кейс — заплатил цену, получил предмет со случайной ценностью.
   Шансы заданы весами по редкостям, легендарка в дешёвом кейсе — 0.3%.
3. Когда все закончили, любой жмёт «финальный расчёт»: банк (сумма всех ставок
   в партии) уходит тому, у кого дропы суммарно дороже. Остальные не получают ничего.
4. «Новая партия» возвращает всем по 1000 и обнуляет дропы.

Бросок детерминированный: предмет считается из хеша
`комната | партия | игрок | номер открытия | кейс`. Один и тот же вход даёт один и тот же
предмет на любом устройстве, поэтому результат воспроизводим и его видно из консоли
через `__battleRoll(кейс, игрок, номер)`.

**Чего здесь нет и не будет:** настоящих денег, пополнения, вывода, ставок и любых
платежей. Монеты существуют только внутри партии и обнуляются.

**Ограничение доверия:** каждый клиент — хозяин своих чисел, поэтому настойчивый игрок
теоретически может подделать свой баланс. Это вечеринка с друзьями, а не казино;
защита от подделки состояния через P2P не делается сознательно.

## Технические заметки

* Никаких внешних шрифтов, CDN и картинок — сайт работает офлайн и грузится мгновенно.
  Единственный вложенный код — `lib/trystero.bundle.js`, он лежит в репозитории.
* `prefers-reduced-motion` уважается: анимации отключаются, вместо них статичный кадр.
* Управление рассчитано и на телефон: свайпы и экранная крестовина в змейке, `touch-action: none`.
* Рекорд змейки хранится в `localStorage` под ключом `neon-snake-best`, имя в мультиплеере — `pg-name`.
* Отправка позиции в мультиплеере живёт на таймере, а не в `requestAnimationFrame`:
  в фоновой вкладке браузер душит анимацию, и игрок иначе «пропадает» из комнаты.
