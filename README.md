# Roof Blueprint & Marker Map

Интерактивная схема кровли: рисуешь контур, ставишь точки-метки с фото и видео,
данные хранятся в браузере и переносятся JSON-экспортом.

Сайт: **https://fermerren2.github.io/playground/**

## Что внутри

* `index.html` — вся программа одним файлом (canvas + интерфейс);
* `interactive_roof_blueprint_media_map.html` — та же версия под исходным именем.

## Важно: внешние зависимости

Этот вариант тянет три вещи из интернета:

| Что | Откуда |
|---|---|
| Tailwind CSS (стили всего интерфейса) | `cdn.tailwindcss.com` |
| Font Awesome (иконки) | `cdnjs.cloudflare.com` |
| Шрифты JetBrains Mono и Inter | `fonts.googleapis.com` |

Следствия, которые надо знать:

* **Без интернета сайт выглядит сломанным** — стилей нет, интерфейс разваливается.
  Предыдущая версия была полностью автономной, эта — нет.
* Tailwind в виде CDN-скрипта сам пишет в консоль предупреждение, что так делать не надо
  для боевого сайта: он собирает стили на лету и весит больше, чем весь остальной код.
* Демо-метки ссылаются на картинки-заглушки `placehold.co` — если сервис недоступен
  или заблокирован, на их месте будут пустые рамки.

Лечится просто: скачать эти три вещи в репозиторий и подключать локально. Пока не делали —
сначала разбираемся с самим приложением.

## Данные

* Черновик хранится в `localStorage` браузера, на сервере ничего не сохраняется.
* «Режим администратора» — переключатель интерфейса, не защита: включить может любой
  посетитель. Сайт публичный, всё нарисованное видно всем.
* Чтобы обновить схему у всех посетителей, нужно экспортировать JSON и заменить файл
  данных в репозитории вручную: браузер сам писать в GitHub не умеет.
